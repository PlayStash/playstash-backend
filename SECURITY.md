# Security

This repository currently uses version 17.0.1 as the fresh PlayStash baseline.

Report security issues through the [repository security page](https://github.com/PlayStash/playstash-backend/security). If private vulnerability reporting is enabled there, use that option for sensitive details. Otherwise, use the [repository issue tracker](https://github.com/PlayStash/playstash-backend/issues) without publishing exploit details or credentials.
